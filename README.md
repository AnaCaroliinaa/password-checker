## 🇧🇷 Português

### 📖 Sobre o projeto

O **Password Checker** é uma aplicação simples desenvolvida em **Python** para analisar a força de uma senha utilizando critérios básicos de segurança.

O programa verifica diferentes características da senha e, com base na quantidade de requisitos atendidos, classifica sua força como:

🔴 **Fraca** • 🟡 **Média** • 🟢 **Forte**

---

###  Funcionalidades

-  Verificação do tamanho da senha
-  Verificação de letras maiúsculas
-  Verificação de letras minúsculas
-  Verificação de números
-  Verificação de caracteres especiais
-  Classificação da força da senha
